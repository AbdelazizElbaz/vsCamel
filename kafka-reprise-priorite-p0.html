Reprise avec priorité par la partition 0 : récapitulatif

La partition 0 du topic principal est réservée aux messages corrigés. Le producteur n'y écrit jamais, et l'instance qui la lit la traite toujours en premier.

Avantages

  • Aucune partition bloquée : en cas d'erreur, le message part dans la DLQ et la consommation continue.
  • Le message corrigé est traité dès son injection, sans attendre derrière les nouveaux messages (M5′ passe avant M13).
  • Pas de topic de reprise à créer : la reprise passe par une partition du topic principal.

Points d'attention

  • Le producteur doit utiliser un partitionneur personnalisé qui n'écrit jamais dans P0.
  • Toutes les instances doivent savoir lire P0 en premier : après un rééquilibrage, P0 peut être attribuée à une autre instance.
  • M5′ est traité par C1, pas par C2 qui lit la partition d'origine (P2). Le traitement ne doit pas dépendre de l'instance.
  • L'instance qui lit P0 a aussi une partition normale. Si les corrections sont nombreuses, on peut donner P0 à une instance dédiée.
